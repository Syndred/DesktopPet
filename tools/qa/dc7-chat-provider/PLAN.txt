显式控制（均仅本地 owned 文件，无新增控制 HTTP 端点）
  node tools/qa/dc7-chat-provider/cli.cjs set-mode --run <实际runDirectory> --mode <模式>
  node tools/qa/dc7-chat-provider/cli.cjs status --run <实际runDirectory>
模式只影响后续请求，不会切换正在进行的流。status 是最后一次文件状态，不探测端口。
stream      约每140ms一个 Unicode 字，显式模拟文本，最后 finish_reason=stop 和 [DONE]。
hold        先逐字发14字（约2秒）后等待，留足正常 UI 取消窗口；最多等待100秒。
truncate    发14字后正常结束 HTTP，但省略 finish/[DONE]，检验不完整 SSE。
disconnect  发14字后断开本次真实 loopback socket，检验部分回复的断流错误。
http401     使用正确 dummy 也故意回401，DC7 应映射 PROVIDER_AUTH。
http429     故意回429，DC7 应映射 RATE_LIMITED；不会伪造真实供应商配额。
http503     故意回503，DC7 应映射 PROVIDER_UNAVAILABLE。
empty       正常结束但无文本，应出现 EMPTY_RESPONSE。
json        回模拟 JSON completion，检验 SDK 兼容路径，不新增第二次网络调用。
