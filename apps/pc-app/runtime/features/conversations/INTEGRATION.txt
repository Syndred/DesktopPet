ui/src/features/conversations/index.tsx 注册 /chat 与 /settings/ai。公共壳自动发现。

正式页面与开源复用
assistant-thread.tsx 实际使用 assistant-ui 的 useExternalStoreRuntime、AssistantRuntimeProvider、
ThreadPrimitive、MessagePrimitive、ComposerPrimitive；输入、IME、发送、停止、消息和滚动由它处理。
外部 store 接已有 SQLite/IPC 领域服务，不使用第三方浏览器存储或客户端模型 SDK。
transport.cjs 实际使用 AI SDK streamText/generateText 与 openai-compatible chatModel；
SSE、JSON 和 provider 序列化由库处理。本模块不再维护手写 SSE parser。
公用 shadcn/Radix：Button、Input、Textarea、Checkbox、Switch、Tabs、Select、Tooltip、Popover、Dialog。
Motion 使用 components/motion 的 AnimatedList 与公共 PageTransition/MotionPanel；
2D 动作调用 companions/CompanionPortrait -> resources/ResourceStage -> PixiJS。
没有本功能专属的精灵播放器；受控弹窗用共享 DialogContent.onCloseAutoFocus 归还焦点，Radix 处理焦点限制。
共享主题变量来自公共样式，模块 CSS 负责 06 三列聊天及 08 AI 设置布局。
批准图、真实 Electron 截图、差异与许可清单见 docs/implementation/status/conversations.json
和 docs/implementation/evidence/conversations/ui-comparison.html。

身份与持久化
所有命令使用主进程的已验证账号与实际 petId。ownerId/ownerAccountId 载荷不能选择账号。
expectedAccountId / expectedSessionRevision 只用于拒绝旧界面操作，不能授权账号。
优先 companions.listPets(ownerAccountId)，兼容已有经验证 RuntimeDataStore 的实例库存。
profiles/messages/memories/connections 均以账号与实例限定；全局连接另有 account 范围。
聊天选择保存在 conversation_preferences，独立于出战、驻守与桌面出场选择。
仅使用 foundation 的单 SQLite 连接和迁移执行器，不打开第二个业务数据库。
退出同步标记中断回复；异常退出的 pending/streaming 在下次注册时恢复为 cancelled。
回滚代码时保留所有 conversation_* 表与 lingjing_migrations 记录，不删除用户文件或旧数据。

命令（成功 {ok:true,data}，失败 {ok:false,code,message}）
snapshot / select / history / profile.save
connection.save / connection.test / connection.cancel
memory.save / memory.delete / send / retry / cancel / history.clear
类型见 packages/shared-types/src/features/conversations/index.ts。
send/retry 流完成后返回，期间事件更新；并发 IPC cancel 中止实际网络请求。
actionId 去重防止重复记录和请求；retry 只允许最后一次失败/取消回复，保留一条用户消息。
profile、memory、connection 编辑使用 revision，拒绝旧版本。

安全模型调用
DeepSeek / OpenAI / OpenAI 兼容 Chat Completions 请求全部留在主进程。
模型 ID 由用户填写；SDK 自动重试关闭，遥测及 prompt/output 记录明确关闭。
支持 SSE、JSON 兼容回复、AbortController、超时、显式重试及 4 个并发请求上限。
忽略 stream:true 而返回 JSON 的接口复用原响应通过 SDK 解析，不再发第二次网络请求。
HTTP 仅允许 localhost / 127.0.0.1 / [::1]；其他接口必须 HTTPS。
禁止 URL 凭据、query、fragment 与重定向；接收网络体硬限 2 MiB，文本硬限 32000 字符。
API Key 经 Electron safeStorage / Windows DPAPI 加密存 SQLite，读取只返回 hasKey。
SDK/provider 原始异常可能含 prompt/key，只转换为固定公开错误码，不返回 renderer 或写日志。
系统安全存储不可用时拒绝保存。更换接口/提供商必须重新填 key，不向新接口转发旧 key。
逐宠物覆盖连接使用自己的 key，不隐式复用全局 key。备份/云同步必须排除 encrypted_key。

上下文与记忆
历史分页 50 条，上下文最多最近 24 个完整对话轮次。
字符预算 12000..48000；记忆最多 6000 字符/24 条；每条 1000 字符，每实例最多 100 条。
人设最多 2000 字符，用户输入最多 8000 字符，回复 token 上限 64..4096。
字符预算不冒充精确 token 计量。记忆由用户明确添加、编辑、删除，没有自动长期记忆抽取。
修改记忆、人设或连接中止使用旧上下文的回复；删除记忆影响后续请求，不删除历史原文。
清空历史不删除单独保存的记忆与人设。

跨模块接点与 2D 范围
conversations:changed：当前会话的 reply/changed，含 accountId、petId、actionId。
conversations:session：清空旧界面并读取当前账号；包含旧登录观察兜底。
conversations:activity：{ownerAccountId,petId,active,pauseWhileChatting}。
getProfile(owner,petId) / isChatting(owner,petId) 由 companions/windows.cjs 消费，暂停当前实例散步。
头像和场景使用 foundation 原创动漫角色素材；其他绑定资源复用共享 CompanionPortrait。
旧形象记录保留，无法用本版资源显示时使用共享资源提示，不尝试载入旧模型。
本模块不导入 model-viewer、Three、GLB/GLTF/VRM；不新增 3D 支持或 3D 测试链路。
按钮平面化，公共 Motion 和 Pixi 都遵守系统 reduced motion 与应用动画开关。
语音 capabilities=false；本次没有假语音按钮或额外 Python/Vue/语音栈。

验收与仍需外部处理的项
11 项真实文件 SQLite + 本机 HTTP 运行时测试通过。
12 项正式 Electron / React / preload / IPC / DPAPI / SQLite 验收通过，实际重启进程和账号切换。
包括共享组件键盘/焦点、表情输入、逐宠物隔离、记忆删除、取消重试、动画开关与 2D Pixi canvas。
没有运行真实云模型：本会话未收到授权模型配置；本机协议 fixture 不算云端模型成功。
foundation 负责最终全模块 Windows 回归与根依赖聚合。此前探索模块类型/依赖问题已由
foundation 修复并合入；本分支最终 typecheck:ui、typecheck 与 build:pc 均通过。
旧兼容 renderer 的明文 AI 设置仍留在历史文件；新 React 路径不使用它。
其安全导入需明确账号映射，不扫描、复制或擅自归属用户旧 key。
账号备份/同步若纳入聊天领域记录，必须保留 owner 归属并排除设备密钥密文。
