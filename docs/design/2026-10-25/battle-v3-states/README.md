# 灵境对战 V3 多状态视觉稿

使用内置 imagegen 生成，未修改应用代码。打开 index.html 可切换五种状态并对比上一版。

- 属性图标紧跟等级，整组位于头像下方且留在卡片内。
- 双方状态卡保持镜像、数值内嵌，右侧头像朝左且条形反向填充；上方卡片留出更宽间距。
- 背景扩展至导航右侧的整片区域，移除独占右侧栏及底部云雾隔断。
- 大招、攻击、属性、闪避四个按钮作为一个整体居中，全部缩小；三个基础圆圈等大，大招稍大。
- 四个按钮直接叠加在背景地面上，半透明且没有独立底部面板。
- 大招始终显示，充能用围绕大招的环形进度表达；移除原有横向进度条。
- 蓄满后金色圆环完整点亮，星芒增强，按钮位置与尺寸不变。
- 回合记录为右下角半透明小卡片，滚动条表明可滚动。
- 悬停说明：攻击=打断属性，属性=无法闪避，闪避=闪避攻击。
