# 灵境 1v1 对战 UI 多状态稿

使用内置 imagegen 生成；本轮仅制作设计预览，未改应用代码。

双击 index.html 切换对比五种状态。

| 状态 | 文件 | 悬停说明 |
| --- | --- | --- |
| 蓄力中 | 01-charging.png | — |
| 悬停攻击 | 02-hover-attack.png | 打断属性 |
| 悬停属性 | 03-hover-element.png | 无法闪避 |
| 悬停闪避 | 04-hover-dodge.png | 闪避攻击 |
| 大招就绪 | 05-ultimate-ready.png | — |

- 双方状态卡镜像：头像在外侧，等级在头像下方且留在卡片内。
- 名字之后紧跟属性图标，右侧名称组靠右，文字保持正常方向。
- 血条和怒气条加高、数值内嵌；右侧条形从右向左填充。
- 回合文案简化为回合2，保留独立倒计时。
- 移除出战伙伴；场内一对一，右侧仅保留回合记录。
- 攻击、属性、闪避共三个等大圆形技能按钮；悬停说明分别为打断属性、无法闪避、闪避攻击。
- 三圆下方显示统一蓄力条；蓄满后在其左侧出现更大的金色大招圆形按钮。

画面中的数值与15s仅作视觉示意。最终生成提示词及来源详见 design-manifest.json。
