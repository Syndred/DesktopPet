关键流程

登录 / 注册 → 我的灵宠 → 独立伙伴详情 → 放到桌面 / 喂养 / 聊天
附近探索 → 野外遭遇 → 挑战 → 收服确认 → 收服结果 → 查看详情 / 放到桌面
好友约战 → 处理邀请 → 对战 → 战报与结算
附近领地 → 入侵 / 驻守 → 对战 → 领地归属与区域捕捉加成
背包选择物品 → 指定伙伴 → 使用数量 → 确认效果
角色资源 → 导入 2D 动画包 / 图集 → 动作预览、锚点 / 缩放 / 帧率校准 → 保存
设置 → 全局 AI 连接 → 单伙伴人设 / 记忆

设计约束

1. 角色模板与宠物实例分开；相同形象可有多个独立实例。
2. 桌面出场、当前聊天、出战伙伴、驻守伙伴是不同的选择状态。
3. 聊天、人设与记忆必须明确归属当前伙伴。
4. 原有对战、定位、捕捉、领地、养成与账号能力保留为正式页面，资源导入仅实现 2D；原始用户数据保留。
5. 源码中的定位服务仍是模拟实现；效果图不代表系统真实定位已经接通。
6. 生成提示词与每张图的来源记录在 generation-plan.json 和 generation-results.json。


菜园更新（v3）

探索/对战获得种子 → 播种 → 成熟收获入库 → 直接喂食或制作米饭 → 指定伙伴喂食 → 继续养成与探索。
基础菜园属于账号，领地提供额外加成；领地易主不清空基础菜园或已收获物品。
