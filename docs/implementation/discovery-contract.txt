返回统一 {ok:true,data,duplicate?} 或稳定 code / 中文 message。

伙伴：调用 companions 的 listPets / getPet / createCapturedInstance。
以 discovery:<encounterId> 为伙伴创建幂等键；伙伴、收服、首次相遇记忆、遭遇状态和操作凭据在同一 SQLite SAVEPOINT 中提交，失败全部回滚。
结果页使用当前实例的 nickname / desktop 命令；同形象的其他伙伴不受影响。结果和图鉴展示读取当前 pet.resource，形象更换后不继续显示首次收服时的旧资源；原始收服凭据保持不变。静态缩略图统一复用 resources.ResourcePortrait 与其构图契约，地图/卡片使用 portrait，图鉴静态大图使用 full，不在本模块维护另一套 atlas 裁切或旧鱼丸兜底图。
origin.memoryTags 同步保存首次相遇标签，conversations 可按真实 petId 读取。

战斗：复用 battle.beginWildChallenge、act、leave 和 getOutcome。
已落盘战斗回合在 snapshot 恢复，不重启战斗、不随机重放客户端动作。
复用 BattleRuntimeService 的五行、怒气、闪避、随机 NPC 和胜负规则，不修改战斗数值。
桌面、聊天、出战选择互相独立；出战与捕获仅接受 2D / spritesheet 资源。
游戏遭遇从 companions.listTemplates 读取 canonical 2D 模板，服务端使用同一模板目录；资源与属性变更生成新的 catalog 身份，旧遭遇继续保留。当前目录已接入鱼丸、小蓝、饭团、焰柴、礼帽喵、小狐的六个独立资源；每个角色都在真实探索预览中确认了共享 Pixi 与 atlas 缩略图。游戏点位按固定地理网格生成，不作为核实过的现实地标。
野外战斗快照附带 battle 的 rules，整个界面直接复用 BattleScreen / BattleArena / useBattleSession / useBattleAnimation；大招门槛、怒气上限、首次免费闪避和禁用原因消费权威配置。辅助规则使用公共图标与 tooltip，不添加探索专有说明或规则。旧遭遇只在公开读回时补规则，既有存档与凭据不被重写。
攻击、属性/大招、受击与胜利姿态消费实际保存的双方回合；动作映射复用 battle，帧播放仍由 ResourceStage / Pixi 负责。资源元数据按身份读取，切换动作保留同一 canvas。应用或系统关闭动画时遵循共享 Motion 策略。

定位：Windows PowerShell 5.1 调 Windows.Devices.Geolocation.Geolocator.GetGeopositionAsync，遵守 Windows 隐私权限。
应用隐私关闭时不调用系统定位；撤销、切号、离开探索页和窗口隐藏会停止持续请求并丢弃迟到结果。探索内部切页在共享 Motion 的有限交接期内保留用户主动开启的监听；离开探索立即停止。Windows hide 可能仍让 document.visibilityState 报 visible，因此主进程额外监听真实窗口的 hide / minimize / close，并禁止隐藏窗口重新开启位置权限上下文。恢复窗口不会暗自恢复持续定位。
取消通过 AbortController 传到 execFile，终止尚未完成的原生辅助进程，而不只是忽略回包。Windows 脚本由 Electron fs 读取并经 EncodedCommand 执行，支持位于 ASAR 内而未解包的脚本；不依赖 PowerShell 直接读取归档路径。
定位与地图投影分开；canonical WGS84，国内 GCJ02 和海外 WGS84 适配保留。
保留 denied / timeout / unavailable / imprecise / stale / demo / privacy_disabled 状态；默认 OS 位置不能收服。
正式互动要求位置年龄 ≤30 秒、精度 ≤80 米、100 米范围，沿用半精度且最多30米的漂移补偿。
系统原始 fix 不随存档落盘；精确位置截图和原始值只留本机忽略目录。
用户开启 Windows 权限后已取得真实 WiFi fix。最新一轮独立原生请求曾取得合格58米样本；随后正式窗口返回177米，60秒主动原生监听始终为313米。58米诊断不等于正式窗口完成收服；真实物理位置收服仍未验收，没有降低80米门槛。
演示模式明确标识且禁止战斗、收服和奖励；测试 host 的受控位置也在界面标明，不能作为真实定位验收。

地图：使用 MapLibre GL JS 6.15.0 管理相机、缩放、拖动、控件、标记和 GeoJSON 图层。
按官方 Vite 用法打包 v6 的独立 worker，避免“底图可见但 GeoJSON 不工作”。样式就绪即可显示标记，远程瓦片慢请求不会阻塞叠加层。
可见瓦片通过主进程 TileCache 请求；Electron net.fetch 遵循现有系统/会话网络配置，独立 User-Agent、6路并发、7天缓存和 OpenStreetMap 署名。
Turf 7.4.0 实际计算 WGS84 距离、精度圆和真实领地多边形包含关系。
默认 OSM 可用；腾讯 / Google 凭据未配置时明确显示不可用，不伪装成已开通。
