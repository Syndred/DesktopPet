Battle 定向验收与 UI 对照 · 2026-10-24

本目录证据来自 Windows 真正运行的 Electron + React renderer。使用 battle 独立测试用户目录，
经实际 accounts 本地登录、companions 领养/选中实例及正式 battle IPC；未使用真实个人账号或原用户目录。
场景与角色是独立素材层，按钮、状态、行动、养成、战报均由实际业务渲染，不是整张设计图或静态网页。

02-live.png：三次实际 UI 出招后的庭院舞台、两张 Pixi 画布、生命/怒气、四行动卡和回合日志。
03-report.png：同一场战斗经过真实进程重启继续，最终失败；5 经验与 2 种子已入库，重复结算没有再发。
04-friends.png：同一个隔离本地账号的好友页面；云端登录不可用状态及未知邀请数量，没有样例联系人。
friends-capture.json：最后的好友不可用状态修正单独验证及截图，未因此重复全套领域回归。
evidence.json：完整 UI 流程、会话 ID、回合数、奖励、实际模块路径、错误和 3D 请求观察。
motion-evidence.json 与四张阶段截图：应用关闭/系统减少动画时，两角色都停止播放。
像素比较解码 PNG 后只容许每通道 1/255 的 GPU 舍入，超过该值即失败；没有按文件压缩字节做假判断。

仍有差异
角色和庭院采用项目原创可动画素材，姿态及插画细节与概念画不逐像素相同。
图稿的 4 个样例宠物、在线好友/就绪灯、邀请数量、倒计时和冷却数值不会伪造到真实界面。
实际账号只有已领养实例；真实免费闪避、怒气门槛、20/5 经验和 garden 种子政策覆盖示例数值。
长战报在实际 ScrollArea 中查看，截图底部之外的回合日志仍可访问。
