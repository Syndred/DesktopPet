项目当前实现及原因
角色插画复用 foundation 按批准角色制作的原创房间插画和八姿态图集；角色身份及色彩一致，具体姿势、面部与裁切不与概念图逐像素相同。未搬用候选项目的受限角色素材。
消息、等级与时间截图保留本机验收文字、真实实例 ID 与实际等级，不填入概念图的示例聊天或 Lv.08。三个同模板形象各有自己的 petId。
安全和真实状态新增密钥保留 / 清除、独立连接和回复预算；不回显已保存 Key。成功状态须收到实际文本，不展示预设云端成功。
记忆与附加输入记忆明确由用户保存，提供添加 / 编辑 / 删除；未实现自动提取、图片附件或语音，因此没有对应假按钮。表情 Popover 可实际插入输入框。
窗口适配窗口尺寸和显示缩放不同于概念画布，AI 设置较长区域可纵向滚动；980×750 检查无横向溢出。按钮平面化，系统与应用动画关闭均已验收。
